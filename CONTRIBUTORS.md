# Authors and contributions

`s100-sampler` was developed at Novia University of Applied Sciences in the MaDaMe project (Maritime Data Methods for Safe Shipping), co-funded by the Interreg Baltic Sea Region Programme 2021-2027.

To cite the software, use [CITATION.cff](CITATION.cff), or **Cite this repository** on the GitHub page.
